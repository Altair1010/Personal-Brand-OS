## Security boundary
The feature is a database-backed secure environment vault; it deliberately does not rewrite the process .env file with user secrets. Agents consume configured values through the server-only vault resolver. Secret reveal is an explicit privileged UI operation gated by .ENV PIN.

## Meta permissions reference
The UI stores configuration only. It does not imply Meta has granted pages_show_list, pages_read_engagement, pages_manage_posts, pages_manage_metadata, pages_messaging, ads_read, ads_management or business_management. Provider/App Review and asset assignment remain external prerequisites.
