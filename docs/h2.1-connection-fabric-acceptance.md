## Implemented

- Canonical ProviderConnection, ProviderResource and ProviderOAuthAttempt persistence.
- Connection states: DISCONNECTED, CONNECTING, CONNECTED, DEGRADED, AUTH_EXPIRED, REAUTH_REQUIRED, REVOKED, ERROR.
- OAuth connect/callback flow from Settings → Connection Center.
- Server-side encrypted access/refresh credentials; no raw token in Connection Center payloads.
- Provider discovery and capability display.
- Verify, refresh, reconnect and revoke operations.
- Meta adapter for Facebook/Instagram resource discovery.
- LinkedIn adapter under the same ProviderConnectionAdapter contract.
- Google Search Console read-only OAuth adapter with offline consent.
- Current tenant/brand scoping for connection queries and actions.
- Meta Facebook Page resources bridge into the existing FacebookAccount channel model.
- Revocation propagates into the legacy FacebookAccount bridge and blocks subsequent publishing/provider metric calls.
